# Relationship with Existing Standards

## ERC-721

ERC-721 defines NFT representation and current on-chain ownership.

This proposal adds temporal projection of external registry state.

## ERC-1400

ERC-1400 focuses on security token compliance and transfer restrictions.

## ERC-3643

ERC-3643 focuses on permissioned token compliance through identity and eligibility controls.

## Asynchronous Register Projection

This proposal addresses a separate problem:

How should externally maintained registry states be represented when they update asynchronously relative to blockchain state?

It is intended to complement, not replace, existing token standards.
